本模块是 `personal_ai_life_os` Python 包的根层，提供 API 进程与桌面 sidecar 进程共同依赖的横向能力：
- 应用入口：`main.py` 通过 `create_app(config, object_store, desktop_secret, desktop_path_key)` 组装 FastAPI 应用，在 lifespan 中按 `processing_mode`（inline/worker）启动后台 worker、调度器、可选的 desktop backup/folder-sync 守护线程，并通过 HTTP middleware 实现基于 `app_env` 的路径鉴权和请求速率限制。
- 配置中心：`config.Settings` 使用 pydantic-settings 从环境变量/.env 加载全部运行时参数，并在生产环境执行严格校验（禁止 open self-registration、强制 S3 后端、SECRET/TOKEN 长度等）。
- 数据访问层：`db.Base` + `create_database_engine`/`create_session_factory` + request-scoped `get_session` 生成器；SQLite 下启用 foreign keys / WAL（desktop）并允许跨线程访问；统一封装 UTC-aware `UTCDateTime` TypeDecorator。
- 领域模型：`models.py` 定义 SQLAlchemy ORM 映射与关联 Table（多对多 junction tables），由 `Base.metadata.create_all` 或 Alembic 管理。
- 安全：`security.py` 使用 pwdlib 做密码哈希、PyJWT HS256 签发含 aud/iss/typ/sub/exp/iat 的 access token。
- 存储抽象：`storage.ObjectStore` Protocol 声明 put/get/delete/deletion tombstone 等接口，`LocalObjectStore` 提供本地磁盘实现，预留 S3 扩展点。
- 进程边界：`cli.py` 基于 typer 构建本地 `lifeos` 命令用于选择/预览/导入本地源；`desktop.py` 作为 Windows sidecar，封装 Alembic 迁移、备份恢复与内置 uvicorn 服务器，并通过 stdin 互传 launcher secret。
依赖方向单向向下：`api/routes/*` → 本模块，本模块内部仅向上依赖自身 services/parsers，不反向引用路由层。
