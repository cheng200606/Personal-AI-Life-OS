所有子领域均实现为独立的 FastAPI `APIRouter` 并通过 src/personal_ai_life_os/main.py 集中 mount 到主 app，而非在各自路由包内自行启动应用；跨领域的横切能力集中在本层提供：
- auth 依赖：deps.py 提供 get_current_user / DeletionUserDep，封装 Bearer token 校验、会话 Session 注入与已注销账户拦截，被各子领域路由复用。
- schema 契约：api/schemas.py 定义跨路由共享的请求体/响应体 Pydantic 模型，避免在各路由间重复声明。
- 权限模型：除 health/metrics 等公开路由外，其余 `/agent`、`/reviews`、`/budget`、`/reminders`、`/search`、`/desktop*` 等路由均以 CurrentUserDep 绑定当前用户，并据此派生 owner_id 做记录级隔离。
- 目录即边界：routes/ 下每个文件对应一个业务域（agent_system、evidence_graph、search_retrieval、desktop_integrations、identity_and_planning、platform_core），main.py 是唯一聚合点，使新增路由只需暴露 router 即可接入框架。
