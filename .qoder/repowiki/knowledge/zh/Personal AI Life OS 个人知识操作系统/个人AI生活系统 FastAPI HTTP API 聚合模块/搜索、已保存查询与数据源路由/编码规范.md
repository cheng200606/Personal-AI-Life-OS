- 所有写入口通过 `_source_or_404`/`_entry_or_404` 等私有辅助函数在 owner_id 约束下加载资源，缺失时抛出带结构化 `detail={code, message}` 的 HTTPException(404)；
- 可恢复的并发冲突用 `try: session.commit() except IntegrityError: session.rollback(); raise HTTPException(..., status_code=409)` 统一捕获并转码为 409；
- 外部不可变配置（如 Settings 中的 consent_version）通过 `request.app.state.settings` 读取并在版本不匹配时拒绝请求；
- 对内部系统功能（如 `kind == 'quick_note'`）显式拒接外部管理接口，避免误操作核心对象；
- 路由按领域拆成独立 `.py` 并通过 `APIRouter(tags=[...])` 注册，前端按 tag 分域访问。
