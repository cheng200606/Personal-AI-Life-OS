三个独立的 FastAPI `APIRouter` 模块，统一通过 `api.deps.CurrentUserDep` + `SessionDep` 注入当前用户与会话以保证 owner_id 隔离。
- `search.py`: 聚合三张表（`SourceItem`/`Review`/`Reminder`）的 `GET /search` 端点；通过 `services.search_index.fts_candidate_filter` 对每个实体类型选择是否走 FTS 候选过滤，未命中时回退到 SQLAlchemy `icontains`；结果以 `SearchTimelineGroup`/`SearchReviewGroup`/`SearchReminderGroup` 拆分返回，片段由内部 `_snippet`/_timeline_snippet 裁剪。
- `saved_searches.py`: 对 `SavedSearch` 模型实现 CRUD `/saved-searches`，使用 `IntegrityError` 处理同名冲突（409），并以字典形态返回以兼容 pydantic v2 的 `model_validate` 入参。
- `sources.py`: 管理 `SourceConnection` 生命周期与同步任务控制（`SyncRun`/`BackgroundJob`），依赖 `services.deletion`、`services.jobs`、`services.graph_evidence`、`storage.ObjectStore` 等外部服务进行删除、取消、证据标记与流式文件下载；内置 `quick_note` 内部源拦截。
依赖方向：routes → schemas/models/services，不直接操作业务逻辑，仅做输入校验、权限边界与响应包装。
