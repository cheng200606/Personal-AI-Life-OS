- 每个路由文件定义一个 `router = APIRouter(prefix=..., tags=[...])`，并将同域端点集中在单个文件内。
- 所有权隔离在所有查询中通过显式追加 `GraphXxx.owner_id == user.id` 条件实现，而非依赖 ORM 级过滤器。
- 可变写端点统一使用 `try/except <Service>Error as error: session.rollback(); raise _error(error)` 模式捕获领域服务异常并转为 HTTP 异常。
- _error 辅助函数将自定义异常的 `status_code`/`code`/`message` 字段映射为 FastAPI `HTTPException` 的 `detail` 载荷。
- 列表查询采用先 `select(func.count()).select_from(subquery())` 计算 total，再取 `limit` 条目的分页模板，并在 response_model 中填充 `total`/`items`。
- 请求/响应数据结构全部经 Pydantic model（schemas 中的 XxxRequest/XxxResponse）进行参数绑定与序列化，不在路由里手写 dict。
