模块由 5 个 FastAPI `APIRouter` 文件组成，按业务领域拆分：
- `graph.py`：GET `/graph/entities` 与 `/graph/relations`，直接以 SQLAlchemy `select()` + 条件拼接实现分页列表和嵌套证据展开。
- `graph_merge.py`：POST `/graph/entities/{entity_id}/merge`、GET `/graph/merges`、POST `/graph/merges/{merge_id}/undo`，委派给 `services.graph_merges`。
- `graph_review.py`：URL 前缀 `/graph/review`，承载待审队列、批量决策 (`resolve_bulk`)、编辑更新 (`update_item`)、单项决策 (`resolve_item`)，依赖 `services.graph_review`。
- `ontology.py`：`/ontology/types` CRUD，依赖 `services.ontology` 创建与状态变更。
- `review_schedule.py`：`/review-schedule` 单记录 GET/PUT，配合 `compute_next_run` 计算下次调度时间。

所有路由共享同一数据访问契约：通过 `CurrentUserDep`、`SessionDep` 注入当前用户与会话；所有读取/写入都按 `owner_id == user.id` 过滤，保证所有者隔离。可变写入口统一采用 `try/except GraphXxxError` + `session.rollback()` + `_error` 辅助映射到 HTTP 400/409 响应体的约定；返回体由 schemas 中的 Pydantic Response 模型序列化。
