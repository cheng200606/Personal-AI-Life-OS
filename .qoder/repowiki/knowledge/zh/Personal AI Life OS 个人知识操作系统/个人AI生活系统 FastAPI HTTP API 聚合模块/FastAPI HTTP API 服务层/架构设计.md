- 包根目录 `api/__init__.py` 仅作为 Python 包占位，HTTP 应用启动时在外部（见 `main.py`/`create_app`）导入各 routes 并挂载到 `app.include_router`。
- `deps.py` 集中声明共享依赖：`SessionDep`（通过 SQLAlchemy `get_session`）、`CurrentUserDep` / `DeletionUserDep`（通过 `HTTPBearer(auto_error=False)` 从请求中提取 bearer token，调用 `security.decode_access_token` 校验后加载 User），为所有路由提供统一的鉴权与 ORM Session。
- `schemas.py` 用 Pydantic `BaseModel` 定义稳定版 API 的请求/响应模型（含 email 标准化等 validator），供路由函数使用；每个路由文件按需 import 自身子集，避免全量耦合。
- 路由以单文件一 `APIRouter` 的形式组织：按领域拆分为 `account/agent/auth/budget/.../sources`，每个文件暴露同名的 `router` 变量，并通过 `tags=[...]` 在 OpenAPI 中分组。无权限的路由（如 `health.py`）仅用 `SessionDep`；受保护路由用 `CurrentUserDep` + `SessionDep`。
- 运维端点独立维护：`metrics.py` 通过 `HMAC.compare_digest` 对固定 metrics token 做无签名鉴权，聚合数据库中的 Job/SyncRun/User/SourceConnection 统计及 `request.app.state.request_samples` 内存采样返回 P95 延迟、失败数等指标；`health.py` 暴露 `/health`（liveness）和 `/ready`（readiness，执行 `SELECT 1`）。
