- 每个路由文件定义一个同名的 `router = APIRouter(...)`，并按功能域设置 `tags=["..."]`，供外部统一 mount。
- 需要用户身份的端点通过函数参数类型注解 `user: CurrentUserDep, session: SessionDep` 声明依赖，鉴权逻辑集中在 `deps.get_current_user`。
- 请求/响应体建模统一放在 `api/schemas.py` 中，以 Pydantic `BaseModel` + `Field` 描述，字段级校验使用 `@field_validator`。
- 错误响应以结构化字典形式经 `HTTPException(detail={"code": ..., "message": ...})` 抛出，而非裸字符串。
- 敏感路由额外从 `request.app.state.settings` 读取配置（如 metrics token、imports_enabled）进行动态开关或鉴权。
