- HTTP 响应使用 `response_model` 绑定到 `api.schemas` 下的 Response Pydantic 模型，请求参数则绑定对应的 Request 模型。
- 业务校验失败统一通过 domain Service 抛出自定义 `*Error`（含 `status_code`、`code`、`message` 属性），再由 `_error` 或 inline helper 转为 HTTPException。
- 所有数据访问以当前登录用户的 `user.id` 为隐含条件对 Model 附加 `owner_id` 过滤，实现 owner-scoped 权限。
- 写操作的数据库事务采用“失败 rollback 并上抛异常、成功 commit 后再 refresh”的两段式模板。
- 路由文件顶部注释用单句 docstring 声明该路由所覆盖的业务子域（如 Owner-scoped agent actions / Local plugin catalog 等）。
