模块由五个独立的路由文件组成，每个文件注册一个 `fastapi.APIRouter`（`/agent`、`/jobs`、`/plugins`、`/model-providers`、`/insights`），作为对外暴露的统一入口。内部依赖方向单向向下：路由层只调用 `personal_ai_life_os.services.*` 中的领域服务，并通过 `personal_ai_life_os.models.*` 直接进行 SQLAlchemy 查询；异常通过 service 抛出的 `*Error`（AgentActionError、PluginError、ModelProviderError、InsightError 等）统一转为 HTTPException，携带 `{code, message}` 结构。所有写操作遵循 `session.rollback()` 后抛出 / `session.commit()` + `session.refresh()` 返回实体的模板。鉴权与 DB Session 通过 `CurrentUserDep`、`SessionDep` 装饰器注入，保证跨域资源按 `owner_id` 过滤。
