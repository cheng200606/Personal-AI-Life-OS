- 路由函数通过 FastAPI 依赖注入获取 `SessionDep`、`CurrentUserDep`，并在每条查询中显式追加 `owner_id == user.id` 条件，以实现数据按拥有者隔离。
- 资源路由返回 Pydantic response model（如 `TagResponse`、`CollectionResponse`、`ReminderResponse`），而非直接暴露 SQLAlchemy 模型实例。
- 唯一性冲突统一捕获 `sqlalchemy.exc.IntegrityError`，rollback 后抛出带结构化 `detail={'code': ..., 'message': ...}` 的 409 HTTPException。
- 需要按主键查找资源的方法被抽取为 `_xxx_or_404(session, owner_id, id)` 小工具，缺失时返回含 code/message 的 404。
- 时间相关计算使用 UTC（`datetime.now(UTC)`），仅在与用户交互处通过 `ZoneInfo` 转换到本地时区。
- 需要读取运行时配置的端点通过 `request.app.state.settings` 获取 `Settings` 单例，而不是在模块级全局读取。
