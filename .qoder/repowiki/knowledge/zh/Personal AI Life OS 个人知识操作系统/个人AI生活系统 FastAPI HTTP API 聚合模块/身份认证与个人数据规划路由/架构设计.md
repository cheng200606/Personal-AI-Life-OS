本模块由若干 FastAPI `APIRouter` 文件构成，每个文件对应一个业务子域（账户、认证、组织、预算、待办项、速记、提醒、审查及其排程），通过各自的 `router = APIRouter(prefix=..., tags=[...])` 聚合后由上层应用挂载。
- 统一依赖来源：依赖注入走 `personal_ai_life_os.api.deps`，提供 `SessionDep`、`CurrentUserDep`、`DeletionUserDep`；模型读写全部经由 SQLAlchemy select/scalar/scalars。
- 鉴权与多租户边界：所有资源型路由参数中携带 user，并通过 `where(Tag.owner_id == user.id)` / `_item_or_404(session, user.id, ...)` 等模式强制 owner_id 过滤；`organization.py` 集中了 `_tag_or_404`、`_collection_or_404`、`_item_or_404` 这类“按 owner 查询并抛 404”的辅助函数。
- 环境门控：`auth.py` 通过读取 `request.app.state.settings.app_env` 区分 desktop 与 web 路径（如 `/auth/desktop-profile`、禁止 web 访问 `/login`）。
- 配置入口集中位于 `Settings`，以 `request.app.state.settings` 形式使用（例如邀请码校验、模型披露、预算上限、访问令牌 TTL）。
- 外部扩展点：认证链路委托 `security.create_access_token`、`model_consent.set_consent`、`model_providers.resolve_model_provider`、`jobs.enqueue_background_job` 等 service 模块；审计/取消等操作委托 services 完成（如 `cancel_all_jobs_for_owner`）。
- 导出类能力：`account.py` 将用户的 SourceConnection/SyncRun/Review/Reminder/Job/GraphEntity 等数十个实体打包为 ZIP 归档；`reviews.py` 支持流式 Markdown 响应 `StreamingResponse`。
依赖方向单向向外：routes → deps/schemas/models/services/config/security/storage，不反向引用其他 route。
