- 服务端侧路径访问一律通过 verify_path_grant(payload.grant, key, purpose) 解析，再对返回值做 is_absolute / not relative_to(data_dir) / 非链接等安全检查后再使用。
- 对外响应结构体使用独立的 Pydantic BaseModel 表示请求/参数，普通查询结果则直接按字段映射为 dict，而非序列化 ORM 对象。
- 更新操作先执行条件式 update(where + status == pending)，再根据 changed.rowcount 判断是否被他人抢先处理，未命中即返回 409 冲突。
- 需要持久化的写操作将 session.commit() 放在成功分支的最后；异常则抛出 HTTPException，并由上层中间件转换。
- 长连接或异步工作流通过 Request.app.state 访问共享服务（desktop_provider、desktop_backup），避免在路由构造函数中持有状态。
