- 四个模块各自导出一个独立 router：analysis(`/desktop/analysis`) 管理桌面 AI 草稿与已确认记录；chats(`/desktop/chats`) 处理大型聊天导入会话；data(`/desktop/data`) 提供原生备份/还原/Markdown 导出；folders(`/desktop/folders`) 负责本地文件夹授权与缺失文件清理。
- 路径验证入口集中在 desktop_chats.py 中的 verify_path_grant：通过 HMAC-SHA256 校验由原生应用生成的 grant payload，所有涉及用户目录写入的路由都复用该函数实现「仅允许在原生文件选择器中挑选」的安全边界。
- 运行时能力从 Request.app.state 读取：request.app.state.desktop_provider、desktop_backup、object_store、settings.data_dir 等，避免在路由层引入构造逻辑。
- 模型写入依赖 personal_ai_life_os.models 下的 SQLAlchemy ORM 实体（DesktopDraft、MemoryRecord、Reminder、SourceConnection、DesktopFolder 等），查询统一采用 SQLAlchemy Core select/join 组合多表。
- desktop_chats 内定义 ChatSession 数据类 + ChatSessions 进程内会话管理器，用 Lock/Event/ThreadPoolExecutor 维护并发导入任务生命周期，并在取消时清空 executor。
- data 与 folders 均复用 desktop_chats.verify_path_grant 与 PathGrant，保持跨模块共享的文件授权语义；folders 进一步调用 services.deletion 与 services.desktop_folders 完成删除与扫描编排。
