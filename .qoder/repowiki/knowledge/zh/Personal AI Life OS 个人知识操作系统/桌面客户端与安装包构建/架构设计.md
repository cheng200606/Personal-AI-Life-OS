本模块是 desktop_client 层，由两类子组件组成：
- Tauri v2 Rust 前端壳 (`desktop/src-tauri/`)：`Cargo.toml` 暴露 `lifeos` 包，依赖 `tauri`、`tauri-plugin-dialog/notification/single-instance`、`hmac/sha2/getrandom/winreg`；`build.rs` 仅作 tauri-build 钩子；`tauri.conf.json` 将上游 `web/dist` 作为前端资源并通过 CSP 限流 IPC/websocket；`src/main.rs` 通过 `CREATE_NO_WINDOW`(0x08000000) 启动 sidecar 二进制，用 stdin/stdout JSON 协议完成握手（secret + path_key），并在 Drop/超时内优雅终止子进程；Rust 侧同时提供 `#[tauri::command]`（autostart、pick_chat/backup/folder 等）以调用系统 Dialog、注册表 (HKCU Run)、通知和托盘。
- Sidecar Python 宿主 (`desktop/build-sidecar.ps1`)：使用 PyInstaller --onedir 把 `src/personal_ai_life_os/desktop.py` + `migrations` + `tzdata` 打包为 `lifeos-sidecar.exe`，并从 `desktop/dist/lifeos-sidecar/_internal/tesseract` 注入 Tesseract OCR 依赖。
- 安装器与部署脚本：`build-installer.ps1` 顺序执行 `prepare-ocr.ps1` → `build-sidecar.ps1` → `tauri build --bundles nsis`；`installer-hooks.nsh` 在卸载时清理 HKCU Run 自启项；`smoke-installer.ps1` / `smoke-sidecar.py` 从可执行路径拉起 sidecar、模拟 500 MiB 大聊天导入与 OCR，校验内存峰值与生命周期。

依赖方向单向：Rust 前端 → sidecar HTTP API；安装脚本 → Tauri CLI → PyInstaller → sidecar 产物。
