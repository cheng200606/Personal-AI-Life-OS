- 子进程通过固定 stdin 协议握手：先写入 secret 与 hex(path_key)，再读取首行 JSON `Ready { port }` 后才视为就绪，并用超时+轮询 try_wait 优雅终止。
- 文件系统访问受 HMAC-SHA256 签名保护：Rust 侧对选中路径生成 `(payload, signature)` 结构体，path_key 仅在 sidecar 内部持有，防止跨进程伪造路径。
- 自动化脚本均以 PowerShell `param([...])` 声明参数并以 `$ErrorActionPreference = 'Stop'` 配合 `throw` 退出，且统一在 `try/finally` 中恢复位置。
- UI 操作全部走 Tauri 插件通道（dialog.notification.tray/menu），不直接使用原生 GUI 库，仅保留 `winreg` 用于 Windows 自启项读写。
