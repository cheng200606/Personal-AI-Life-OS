模块按两类职责划分：
- 本地开发环境（.devcontainer/）：以 `Dockerfile` 基于 Ubuntu 24.04 + uv 镜像，并在其中安装 CJK 字体；`devcontainer.json` 启用 Docker-in-Docker、Node 24 与 SSH，暴露 5173 端口并自动打开 Web 客户端，通过 `postCreateCommand` 运行 `setup.sh` 完成依赖同步、Playwright 浏览器安装以及 `docker compose -p lifeos-iteration ... up` 启动完整服务栈。
- GitHub Actions 流水线（.github/workflows/）：`ci.yml` 在 Ubuntu 上对 Python 3.11/3.12 矩阵执行 ruff lint + pytest，并对 web 目录执行 npm lint + build，再以 docker-compose 做容器冒烟测试（curl /api/v1/health 与 /ready）；`desktop.yml` 仅在桌面相关路径变更时触发，在 Windows 上编译 Tauri、运行 desktop MVP 测试、打包 NSIS 安装器并上传 artifact。依赖方向为单向：流水线与开发环境仅消费项目根仓库中的脚本（uv.lock、pyproject.toml、web/package-lock.json、desktop 下的 PowerShell 脚本），不反向依赖业务代码。
