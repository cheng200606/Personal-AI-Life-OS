模块以 Vite (React 插件) 为构建与开发入口 (`vite.config.ts`)，`src/main.tsx` 在检测到非 Tauri 环境时注册 PWA Service Worker (`src/pwa.ts` + `public/sw.js`, `manifest.webmanifest`)。应用内采用单文件路由：`App.tsx` 将 `/timeline`、`/ask`、`/graph`、`/pending`、`/projects`、`/reviews`、`/search`、`/organize`、`/account`、`/capture` 等路径映射到 `Page` 枚举，并动态引入 DesktopChatImport、DesktopFolders、DesktopAnalysis、DesktopData 等页面组件；其余通用类型与状态集中在该文件。

双运行时架构通过 `src/desktopRuntime.ts` 抽象：Tauri 模式下调用 `invoke` 并携带 `X-LifeOS-Desktop` 密文转发请求至本地后端；浏览器模式直连 `VITE_API_BASE_URL`，由 Vite dev server 将 `/api` 反向代理至 `LIFEOS_API_ORIGIN`（默认 `127.0.0.1:8000`）。导出能力统一走 `vaultExport.ts`，再经 `desktopExport` 触发 `desktop_pick_folder` 选择目录写入。

部署侧提供 `Dockerfile` / `Dockerfile.dev` + `nginx.conf` 作为静态资源镜像；E2E 使用 Playwright (`e2e/*.spec.ts`, `playwright.config.ts`)，Linter 使用 oxlint (`package.json` → `.oxlintrc.json`)。
