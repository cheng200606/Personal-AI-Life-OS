- API 调用封装为 `apiFetch` 与 `desktopRequest`，统一附加 Authorization/Bearer Token 及 Content-Type 头，并把 HTTP 错误转换为带中文 message 的 Error。
- 对外部 payload 一律使用 `Record<string, unknown>` 接收后显式构造 TS 类型字段，避免直接 `any`。
- 所有用户可见的错误消息与 UI 提示均使用中文字符串，而非英文硬编码。
- PWA 能力（共享捕获、通知）与浏览器-only 初始化通过 `isTauri()` 判断进行分支，非桌面运行时才会注册 Service Worker。
