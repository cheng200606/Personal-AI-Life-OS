- 外部配置错误统一通过继承 `RuntimeError` 的领域异常类（如 `ModelProviderError`）抛出，并附带 `code`/`message`/`status_code` 三元组以支持上层转为 HTTP 响应。
- 供应商等不可变配置使用 `@dataclass(frozen=True, slots=True)` 定义，并通过工厂函数在构造时完成 base_url 规范化、loopback 检测与价格字段的 Decimal 安全解析。
- 提供者默认 ID 与披露文案常量集中定义在模块顶部（如 `DEFAULT_PROVIDER_ID`、`DEFAULT_DISCLOSURE_DATA`），供 providers 与 consent 共享以避免散落的魔法字符串。
- 同意逻辑先查表 `consent_record`，若无记录则回退到 `user.ai_consent_*` legacy 字段以兼容旧版本用户（仅对 builtin default provider 启用）。
- 敏感操作（set_consent enabled）前置检查 provider 是否具备 api_key/local、rates_configured 与 disclosure_ready，任一不满足均抛出对应 code 的领域异常而非直接报错。
