- 所有子模块均通过 `personal_ai_life_os.db.create_session_factory(engine)` / Base.metadata 访问 SQLite 或 PostgreSQL，并通过 `create_object_store` 的 ObjectStore 做文件对象存储，构成跨子模块的数据边界。
- 顶层 `main.py::create_app` 在 FastAPI lifespan 中统一拉起 background worker 线程 (`jobs.worker_loop`)、schedule-loop 线程 (`scheduling.schedule_loop`)、可选的桌面 folder-backup 线程，并调用 `deletion.replay_deletion_tombstones`、`search_index.ensure_sqlite_search_index` / `ensure_postgres_search_indexes` 完成启动期初始化。
- API 路由层位于 `api/routes/*`，只消费本目录的服务函数；各子服务不直接依赖彼此，而是经由主进程状态（settings/engine/session_factory/object_store）和公共 DB schema 解耦，例如 model_services 通过 settings/consent 影响 ingestion/graph_pipeline，graph_pipeline 的输出被 scheduling 写入搜索索引并生成 review 任务。
- `plugins.py` 暴露的本地插件机制与本目录内的 `agent_actions.py`、`ontology.py`、`quick_notes.py` 共同作为可插拔的业务扩展点，供外部代码在主进程中注入新动作或问答钩子。
