- 每个迁移文件声明 Python 型注释的 `revision` / `down_revision` / `branch_labels` / `depends_on`，并使用 `revision: str = "..."` 形式定义
- 所有实体主键与关联 ID 统一使用 `sa.Uuid(as_uuid=False)` 类型存储为字符串
