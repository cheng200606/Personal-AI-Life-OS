- 项目以 `pyproject.toml` 为唯一 Python 依赖入口（`uv sync --locked`），`src/personal_ai_life_os` 通过 `lifeos` CLI 暴露命令行入口；`backend_api`（FastAPI）、`backend_services`、`backend_parsers`、`backend_shared` 在同一包内构成后端四层。
- `backend_api` 在 `main.py` 集中挂载路由并依赖 `backend_shared` 的 `deps.CurrentUserDep`、配置、存储抽象等基础设施；`backend_services` 提供跨 API/CLI/桌面 sidecar 复用的业务服务；`backend_parsers` 产出统一的 `ParsedItem` 被调度层消费。
- 数据库由 `database_migrations/Alembic` 管理版本演进，迁移脚本由 `migrations/` 目录随镜像一并发布，运行时通过 alembic.ini 连接 PostgreSQL；对象存储走 `backend_shared` 定义的协议供解析器和索引层复用。
- `web_app`（Vite+React）与 `desktop_client`（Tauri v2 + PyInstaller sidecar）作为前端面，通过 HTTP API 或 Tauri 桥访问同一后端；`scripts_and_evaluate` 提供 pg_dump/S3 运维及合成数据评测。
- `tests`、`fixtures`、`devcontainer_and_ci` 位于根级，为所有子模块提供 pytest 用例、固定数据和 GitHub Actions/Docker 一体化构建流水线。
