- Python 脚本统一使用 `from __future__ import annotations`，通过 FastAPI `TestClient` + `create_app` 构建端到端用例而非绕过 API 直接调业务函数。
- 基准/评测脚本以命令行参数（`--host`/`--port`）结合 `argparse` 暴露可调配置，并通过 JSON 文件（如 `fixtures/synthetic/review-eval.json`）装载固定测试集，保证结果可复现。
- 运维 shell 脚本遵循 `set -euo pipefail`、通过 `command -v` 前置检查依赖、并用 `trap 'rm -rf "$TEMP_DIR"' EXIT` 清理临时目录，敏感变量通过 `${VAR:?error}` 必填校验。
