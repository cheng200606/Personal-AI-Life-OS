脚本目录按职责分为四类独立可执行单元，互相不形成依赖环：
- 运维备份类：`backup-production.sh` / `restore-production.sh` 是受 shellcheck 约束的 bash 流程，强制从 `.env` 加载环境变量并通过 `docker compose exec db` 调起 `pg_dump`，再经 `aws s3 cp/sync` 落盘并生成含 `backup_id` 的 `manifest.json`；`register-scheduled-sync.ps1` 负责 Windows Azure Functions 定时任务的注册。
- 评测与基准类：`evaluate_reviews.py`、`evaluate_graph_qa.py`、`evaluate_search.py`、`benchmark_mvp.py` 均基于 `personal_ai_life_os.main.create_app` + FastAPI TestClient 在内存或隔离 SQLite/PostgreSQL 中构造合成数据，调用真实 `/api/v1/*` 端点，用 `Counter`/P95 统计事实准确率、引用完整性与时延指标，结果输出为 JSON。
- 校验演练类：`verify_database_restore.py` 作为被引模块由 `verify_joint_restore.py`、`verify_photo_ocr.py` 共同复用，借助 boto3 对本地 S3 模拟器（默认 `http://127.0.0.1:15666`）进行联合回滚排练。
- 测试代理类：`serve_review_eval_provider.py` 通过内置 `http.server.ThreadingHTTPServer` 实现一个最小 OpenAI `/v1/chat/completions` 兼容的回环提供者，供评价管线在不接入真实模型的情况下运行。

外部依赖方向单向指向 `personal_ai_life_os`（config、main、models、api.routes）和第三方库（boto3、fastapi/testclient、sqlalchemy），脚本之间仅通过 import 关系由校验类相互协作。
