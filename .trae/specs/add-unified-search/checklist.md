# Checklist

- [x] `GET /api/v1/search` 需要登录，且时间线、复盘、提醒三组结果都只包含当前用户的数据
- [x] 查询词去空白后长度必须在 1–200 字符；空白或超长返回 422
- [x] 时间线结果排除已删除、非当前版本和来源处于 `deleting` 的记录；复盘排除 `invalidated`
- [x] 每组默认返回 10 条、最多 20 条，并返回该组总数
- [x] 结果排序确定：标题命中先于正文命中，时间线与复盘按时间倒序，提醒按到期时间升序，ID 兜底
- [x] 每条结果片段不超过 200 字符，响应不返回完整正文
- [x] 检索不写入查询词或结果正文到日志/指标，也不触发外部模型或网络调用
- [x] Web 侧边栏存在 Search 入口，输入框有可访问标签，支持 Enter 与按钮提交
- [x] Web 覆盖加载、空态、无结果和错误状态；失败后保留已输入查询词
- [x] 时间线结果可跳转到 Timeline、按来源筛选并定位条目
- [x] 复盘结果可跳转到 Weekly review 并定位对应复盘卡；提醒结果可在 Weekly review 中找到
- [x] 键盘可聚焦搜索入口、输入框和结果链接，并完成一次检索
- [x] 合成评测包含至少 20 条中英文查询，输出前 5 条命中率、P95、数据规模与运行环境
- [x] 1 万条时间线加复盘/提醒的检索 P95 ≤500 毫秒，或已记录未达标原因并明确不引入索引
- [x] `uv run ruff check .` 与 `uv run pytest -q` 通过
- [x] `npm run lint`、`npm run build` 与 `npm run test:e2e` 在 `web/` 通过
- [x] 未新增数据库迁移、第三方依赖或外部模型调用
- [x] 支持矩阵、架构概览、里程碑、迭代记录与 README 已更新实际范围、限制和评测结果
- [x] `git diff --check` 通过
