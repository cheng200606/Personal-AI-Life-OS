# Personal AI Life OS 桌面 MVP 迭代

适用范围为 Windows 10/11 x64 单人本机使用。工作区复用现有 React、FastAPI、SQLite 和本地对象存储。用户在首次启动创建本机个人资料，随后可以在本机导入和检索，经逐来源授权调用外部 AI，审核有出处的草稿，再进入周复盘、提醒和 Obsidian 导出。

## 文件与云端边界

- 文件夹需通过原生选择器授权。关闭主窗口保留托盘和同步。开机启动默认关闭，撤回目录授权后停止同步。
- 聊天白名单按稳定会话 ID 保存。更新时新会话默认排除。ChatGPT JSON 与带稳定 ID 的会话对象 JSON/JSONL 可通过桌面流式导入。原型限制单文件 1 GiB、单会话 32 MiB。性能预算暂定 500 MiB 的合成预览在 30 秒内完成，峰值工作集低于 250 MiB。
- Obsidian Vault 作为只读来源，排除系统目录和 Life OS 导出目录。写入需用户显式选择目标，照片和 ICS 继续走手动导入。
- 同步发现源文件删除后，从新检索与分析中排除相应记录并等待用户确认。恢复备份要应用当前删除日志。
- 云端分析须有来源和对应提供方授权，受单次和月度预算约束。AI 草稿按工作与学习经历、可复用知识与关系、行动建议排序，逐条呈现引文和置信度。
- 依赖 Windows 用户账户保护本机资料。提供方密钥保存至 Windows 凭据管理器，备份排除密钥。

## 验收主流程

1. 在干净 Windows 安装并创建本机资料，重启确认资料保留。
2. 选定 Markdown 目录、Vault 与聊天导出目录，并独立设置云端分析权限。
3. 本机读取至少 500 MB 的导出，导入已选会话。更新文件后只同步白名单。取消或重新导入后核对重复记录。
4. 关闭窗口，在授权目录修改文件。确认托盘同步，撤权后确认停止。
5. 审核三类草稿，核对原文，编辑、确认、拒绝并预览后批量接受。
6. 完成搜索、问答、周复盘、提醒与显式 Obsidian 导出。
7. 删除源文件，处理待确认记录，再恢复先前备份。确认已删除数据保持删除。
8. 在没有云端授权、断网和预算耗尽的情况下验证本地导入和检索，并检查任务状态及重试。
