## 4. 风险与退出规则

- **资源或权限迟到。** 本地候选、自动化和演练脚本独立交付，托管排期从 B0 准备就绪开始。
- **重启、租约过期或撤权造成竞态。** 在 PostgreSQL 停掉 worker，另用进程重新领取。记录原任务状态、结果和费用，复核迟到结果及旧领取者是否还能写回。

- **问答。** 确定性本地检索不调用云端模型；答案包含结构化事实、原文引用、置信度、事实/推断/不确定标记、缺失信息与行动建议。来源、项目/主题与时间范围可筛选，线程记住上次范围；撤回来源、删除条目、失效证据和未批准实体不会进入答案。
- **历史。** 问答线程本地保存，支持追问、JSON/Markdown 导出与删除；引用可跳回时间线原文。
- **边界。** 抽取仍只有 API 入口，Web 暂无手动选择条目触发抽取；问答为关键词与规则检索，并非语义模型；首屏延迟以本地毫秒计时，不代表真实资料规模；Agent 自动行动、规则洞察与插件 SDK 仍属后续 Task 6–8。

## 7. M5 统一检索（已完成）
