## 4. 风险与退出规则

- **资源或权限迟到。** 本地候选、自动化和演练脚本独立交付，托管排期从 B0 准备就绪开始。
- **重启、租约过期或撤权造成竞态。** 在 PostgreSQL 停掉 worker，另用进程重新领取。记录原任务状态、结果和费用，复核迟到结果及旧领取者是否还能写回。
- **灾备复活已删资料。** 使用独立保全的删除账本，把晚于快照的删除纳入恢复演练。恢复证据和保留窗口缺失时继续合成环境。
- **本地性能与 OCR 结果不可外推。** 记录目标镜像、语言包、托管规格、样本和测量方法，分别报告失败与延迟。范围不明的格式保留为待确认。
- **小样本不足以判断竞争力。** 同时保留成功、放弃、返工时间和计量分母。指标未达时优先修复最早且影响最大的一环，用同一任务复测。

候选版本须通过 A1–A4。真实资料准入须通过 B1–B3 并附可复核记录。发生跨账号访问、删除失效、恢复后资料复活或不可恢复的数据损坏时，维持合成环境并修复复测。用户结果决定 C1 后的扩容与功能投资。 [发布清单](../operations/release-checklist.md)
