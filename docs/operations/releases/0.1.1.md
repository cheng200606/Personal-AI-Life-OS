# Personal AI Life OS 0.1.1 本机发布候选记录

2026-11-27。本记录对应单人本机 Windows 桌面候选版；不构成公开分发、签名或自动更新承诺。

## 概要

- **产品版本：** 0.1.1，权威来源为 `desktop/src-tauri/tauri.conf.json`；`Cargo.toml`、`pyproject.toml`、`Cargo.lock`、`uv.lock` 与包 `__version__` 由 `tests/test_desktop_release.py` 校验一致。
- **范围：** Windows 10/11 x64、单人本机、合成资料。真实个人资料仍未获准使用；托管与他人使用仍未就绪。
- **基线 commit：** `cb3c8a8`（2026-11-27）。产物构建时工作树另含 R1 的版本统一、F1 修复（Web OpenAPI 版本）与文档校准改动；仓库尚未提交这些改动，因此产物与具体 commit 之间只有构建时间关系，不是加密绑定。
- **可复现性：** 安装包不是按字节可复现构建；产物身份以 SHA-256 与归档路径为准。
- **F1 修复（2026-11-27）：** Web 模式 FastAPI 曾硬编码 `version="0.1.0"`，导致 `app.openapi()["info"]["version"]` 与产品版本不一致；现已改为引用包 `__version__`，并有回归测试锁定。修复后重新构建与冒烟，修复前的 version-aligned 产物保留在 `pre-api-version-fix/`。
