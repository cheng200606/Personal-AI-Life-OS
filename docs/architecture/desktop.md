# Windows 桌面架构

桌面版面向 Windows 10/11 x64 上的单人本机使用。开发阶段与环境验收见 [桌面 MVP 方案](../roadmap/desktop-mvp.md)。

## 进程与本机身份

```text
Tauri 2 + WebView2
  React/Vite 工作区
  Windows 托盘、单实例、原生选择器、可选登录启动和提醒
  Python sidecar 监督、就绪检测与退出
        │ 127.0.0.1 随机端口 + 启动密钥 + 会话令牌
        ▼
PyInstaller one-folder
  FastAPI、SQLAlchemy 和 Alembic
  SQLite WAL、本机对象存储、删除日志
  OCR、周复盘调度、目录同步、分析队列、自动备份
```

- Tauri 通过匿名管道传入每次启动新生成的 API 密钥和原生选源签名密钥。Python 直接绑定随机回环端口，完成迁移、删除日志重放和服务启动后通过 stdout 报告端口。
- React 调用就绪探针，首次由用户创建本机个人资料。以后由 Windows 用户账户和当前桌面进程恢复会话，渲染器仅在内存中保存令牌。窗口关闭时留在托盘，显式退出关闭 sidecar 管道。启动或运行失败可在应用中重试。
- 桌面 API 禁用注册和邮箱登录，CORS 限于桌面来源。目录、聊天文件、导出和备份使用用途限定的短期原生路径凭证。
- 默认无云端提供方、未授权目录、登录启动关闭。工作区受当前 Windows 用户目录权限保护，应用不增加独立解锁密码。

## 数据目录

```text
%LOCALAPPDATA%/PersonalAILifeOS/
  data/lifeos.db               SQLite 与迁移版本
  objects/                    已导入原件和删除日志
  logs/sidecar.log             轮转、无正文的运行日志
  migration-backups/          迁移前数据库快照
  provider.json               提供方和预算配置
  backup-settings.json        备份目标位置
```

API 密钥使用 Windows 凭据管理器。备份包含 SQLite 和其引用的对象以及删除日志，凭据、提供方配置和运行令牌排除。恢复在 sidecar 停止后切换数据目录，合并本机最新删除日志，并在服务就绪前重放。恢复的目录和云端授权需要用户重新启用。

## 导入和同步

- Markdown 和 Vault 每隔约 3 秒检查授权目录。排除隐藏目录、Windows 重解析点及 Life OS 导出。文件身份由相对路径确定，内容版本去重独立于其他文件。
- 聊天在本机逐会话读取。原生文件选择后显示会话目录，可取消和重试。经用户选择可将白名单保存至已授权聊天目录，之后只检查登记的文件及会话 ID。新会话默认排除。文件更新走现有入库和索引。
- 监测到文件移除后隐藏其当前条目并送入待确认列表。确认删除通过删除日志清理记录、索引可见内容、相应派生记录及未被其他条目引用的对象。
- 选中的照片和 ICS 沿用手动导入。Obsidian 导入只读，用户显式导出到所选目录下的 `LifeOS-Exports`，遵守保留、另存和覆盖策略。

## 模型与审核

- 来源级授权和提供方授权分别生效。可配置一个 OpenAI 兼容端点、模型、价格、每次和每月预算。模型调用使用当前授权版本，先按预算预留，调用失败仍可在任务列表和用量中查看。
- 导入产生新版本时，按来源与条目生成可恢复的持久任务。模型接收有上限的文本摘录。仅接纳带原文精确引用且通过置信度门槛的草稿。
- 草稿按来源归组，展示经历、知识与关系、行动建议。用户可编辑、确认、拒绝或预览批量确认。确认的经历与知识保留来源关联，行动进入提醒。外部 AI 不可用时本机索引、问答和模板复盘仍可用。

## 构建和发布

- 开发工具链为 Node 24、Rust/MSVC、Python 3.12 x64 和 PyInstaller。Windows x64 NSIS 以当前用户安装，依赖系统 WebView2，安装包带 Python、SQLite、迁移和 Tesseract 英文及简体中文模型。
- 自动化构建、验证命令与人工环境要求见 [桌面本地验收](../operations/desktop-acceptance.md)。
- 公开分发前验证代码签名与签名更新、SmartScreen 和升级回滚。Web/托管门禁独立于本机验收。
